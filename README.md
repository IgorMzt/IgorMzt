# Projetos em destaque

## 🏋️ Gym OS

Sistema completo para gerenciamento de academias, desenvolvido com foco em automação, segurança e experiência do usuário.

**Principais recursos:**

* Gestão de alunos
* Gestão de professores
* Controle de acesso
* Reconhecimento facial
* Integração com catracas
* Controle de planos e vencimentos
* Integração com pagamentos
* Dashboard administrativo
* Sistema de treinos
* PWA para alunos
* API para integração com aplicativo mobile

**Stack:** Python • Flask • SQLite • JavaScript • HTML • CSS

[Ver projeto no GitHub](https://github.com/IgorMzt/Gym-Os)
